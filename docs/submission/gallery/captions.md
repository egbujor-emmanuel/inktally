# Gallery captions (paste one per image on Devpost)

1. **01-web-and-android** — REDPEN marks handwritten classwork on the teacher's own laptop or phone: the same app on web and Android, one shared data model.
2. **02-quick-mark** — Quick mark on a real handwritten page: the answer key is worked out from the questions only, then the page is marked 4/6 with both wrong answers caught.
3. **03-offline-gemini-nano** — Offline, on real Gemini Nano: each answer box is read on the device and marked by code. Marks stay *Provisional* — here the device read a "D" as "A".
4. **04-cloud-check** — Back online, the cloud checks every on-device mark by itself, and remembers the device's misreads so matching readings are held for the teacher next time.
5. **05-marked-copy** — The marked copy: the student's own page with ticks, crosses and the total, ready to share or print.
6. **06-answer-key** — The answer key stays editable after marking; every student is re-marked from what REDPEN already read.
7. **07-register** — Mark register: every student and question, editable names and comments, Excel download.
8. **08-galaxy-s26** — The Android app on a real Galaxy S26 (Samsung Remote Test Lab). Gemini Nano isn't open to apps there, so REDPEN says so and reads in the cloud.
