InkTally marks handwritten classwork on the teacher's own phone, even with no internet.

Built for #BuildHybridAI with @Firebase AI Logic. 2-minute demo ↓
[video]

2/
The phone reads each answer with Gemini Nano, on the device.
Plain code does the marking against the teacher's own marking guide: objectives, numbers with units, method marks, theory points.

3/
When the signal is back, Gemini in the cloud reads every answer again.
A mark is "Verified" only when both readings agree. Anything else goes to the teacher, with both readings side by side.

4/
It handles real exam papers: paste a WAEC-style marking guide and it keeps the paper's own labels, like 6(b)(ii).
Wrong formula but tidy arithmetic? No method mark, and it's flagged.

5/
Web and Android, identical. Records sync through Firestore when you're back online.
Every number we publish is re-checked against its evidence file by one command.

6/
