InkTally — handwritten classwork marked on the teacher's phone, even offline (#BuildHybridAI)

=== Description ===
InkTally marks handwritten classwork on the teacher's own phone or laptop, even with no internet. Gemini Nano reads each answer on the device, plain code marks it against the teacher's own marking guide, and when the signal comes back Gemini in the cloud reads every answer again. A mark is "Verified" only when both readings agree.

Built for #BuildHybridAI 2026 with Firebase AI Logic hybrid inference (PREFER_ON_DEVICE, ONLY_IN_CLOUD, PREFER_IN_CLOUD), App Check, Remote Config, Firestore offline, Authentication and Hosting. Web (Chrome) and Android.
