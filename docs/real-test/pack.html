How to run this test

This pack tests REDPEN on real handwriting with demanding questions: multiple choice, calculations with working and units, fractions, spelling, and theory answers marked point by point. We already know the correct mark for every answer, so we can see exactly where REDPEN agrees and where it doesn't.

  1. Find 4 people (different handwriting is the point). Give each person one script page: Script 1, 2, 3 or 4.
  2. Each person copies their script by hand, in pen, onto one clean exercise-book page, in their normal handwriting. They write the question numbers clearly, copy the answers exactly as printed (including the mistakes), and don't add anything.
  3. At the top they write only “Script 1” (or 2, 3, 4). No real names.
  4. Photograph each page flat, in good light, one page per photo. Also photograph the marking guide page, or just send the PDF.
  5. Put the photos in Google Drive, in a folder called REDPEN real scripts, and tell me.
Then: I create the assignment from the marking guide, mark the four scripts with REDPEN (cloud, and real Gemini Nano offline), and compare every mark with the correct one. That run is also our demo footage.

Optional: if you can print, create the assignment in REDPEN from this marking guide, print its answer sheets, and have people write in the boxes instead of an exercise book.

Keep the separate "truth" file to yourself. Don't give it to the writers.
